# auto-wirecutter
A combined hardware and software project for building an automatic wire feeder and cutter. The device measures wire length with precision and cuts it to the desired length. Ideal for electronics manufacturing, prototyping, or automation setups.

This repository contains the code and hardware documentation for a custom-built "Wire Feeder and Cutter" system.

✅ Automatically measures wire length
✂️ Cuts wire to user-defined length
⚙️ Powered by microcontroller-based control (e.g. Arduino/ESP32)
🛠️ Includes hardware schematics, firmware, and optional PC control interface

The system is designed for small-scale production environments or labs where repeated and precise wire cutting is needed.
